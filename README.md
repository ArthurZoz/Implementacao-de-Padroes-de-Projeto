# Implementacao-de-Padroes-de-Projeto

**O Trabalho foi realizado com ajuda de LLM(gemini).**
**O materiais de estudo utilizados, assim como a base para os códigos, foram retirados do site <https://refactoring.guru/pt-br/design-patterns>.**

## Descrição:
Este é um trabalho da matéria de Engenharia de Software sobre padrões de projeto. 
O objetivo é descrever três padrões de projeto (um comportamental, um criacional e um estrutural), além de implementar e explicar cada padrão.
No meu caso, todo o código do trabalho foi escrito em linguagem c++, veja mais abaixo.

## Código Singleton

O código está localizado em ~/Implementacao-de-Padroes-de-Projeto/Singleton/Codigo_singleton.
Para rodar o código basta abrir o terminal na pasta e executar o comando **make**.
Para deletar o executável, utilize **make clean**.
O texto com a explicação do modelo singleton e do código está localizado em ~/Implementacao-de-Padroes-de-Projeto/Singleton/Padrao_Singleton.pdf
